WHY CHEMISTRY PREDICTS QUALITY

From chemical properties to intelligent predictions

Wine quality can be influenced by measurable chemical properties — acidity, sugar content, sulfur dioxide levels and more. Our machine learning system learns patterns from historical wine data and uses those patterns to predict the quality of new wine samples, without relying on human tasting alone.

01

Measured, not tasted

Every input is a lab-measurable chemical property, so predictions are reproducible and explainable.

02

Two models, compared fairly

A single Decision Tree is trained alongside a Random Forest ensemble under identical evaluation conditions.

03

Tuned, not guessed

GridSearchCV searches hyperparameters and cross-validation confirms the result generalizes.

ALGORITHMS

Decision Tree vs. Random Forest

MODEL 01

Decision Tree

A Decision Tree makes predictions by asking a sequence of decision questions and creating a tree-like structure, splitting the data at each step until it reaches a prediction.

Alcohol > threshold?
  ├── YES → Volatile Acidity > threshold? → Prediction
  └── NO  → Sulphates > threshold? → Prediction
ADVANTAGES
  • Easy to understand
  • Easy to visualize
  • Simple interpretation
LIMITATION
  • A single tree can overfit complex datasets
MODEL 02

Random Forest

Random Forest combines multiple Decision Trees, each trained on a different sample of the data, and uses their combined predictions to produce a more robust result.

Tree 1 ─┐
Tree 2 ─┤
Tree 3 ─┤ → Random Forest → Prediction
Tree 4 ─┤
Tree 5 ─┘
ADVANTAGES
  • More robust
  • Reduces overfitting compared with a single tree
  • Usually stronger predictive performance
TRADE-OFF
  • Less directly interpretable than one tree

How these results were produced

Both models were trained on the UCI Machine Learning Repository's Wine Quality (red wine) dataset (1,599 samples; 240 duplicate rows removed during preprocessing, leaving 1,359). Because raw quality scores are sparse at the extremes, they were grouped into three classes — Poor (≤4), Average (5–6), Good (≥7) — matching the "Good / Average / Poor" labels used on the Predict page. Hyperparameters were selected with GridSearchCV (5-fold), and 5-fold cross-validation was used alongside a held-out 20% test split for evaluation. If your own coursework requires results on a different split, dataset variant (e.g. combined red + white), or binning scheme, re-run train.py (included in the project files) and these numbers will update accordingly — nothing here is hand-typed.
